# 雪场规划系统 · Ski Resort Planner

浏览器内的雪道地形与雪面渲染系统：TypeScript + WebGPU，零运行时框架依赖。

## 功能页面

| 路由 | 页面 | 能力 |
| --- | --- | --- |
| `#/resorts` | 雪场列表 | 新建（256/512/1024）、复制、删除、JSON 导入导出，IndexedDB 持久化 |
| `#/terrain` | 地形编辑 | 抬升/压低/平滑/推平刷子、拖拽插值、程序化 fBm 地形重生成 |
| `#/guns` | 造雪布点 | 造雪机摆点与参数、风向风速工况、Worker 异步积雪计算、双跑哈希自检 |
| `#/grooming` | 压雪路线 | 折线绘制、车宽栅格化车辙、覆盖率/里程统计 |
| `#/preview` | 渲染预览 | WebGPU 3D 地形、次表面散射/闪光颗粒/阴影偏蓝、坡度标红、时间滑块 |
| `#/settings` | 设置导出 | 安全坡度阈值、可复现性自检、厚度图 PNG/BIN、坡度 CSV 导出 |

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm test           # 确定性与性能测试（16 项）
npm run build      # 类型检查 + 生产构建
```

WebGPU 需要 Chrome / Edge 113+。不支持时预览页会显示明确提示，其余 2D 页面不受影响。

## 核心设计：积雪厚度的可复现性

`src/domain/snow.ts` 是纯 CPU 确定性引擎，保证**同样输入两次计算结果位级完全一致**：

1. **固定处理顺序**：造雪机按 `id` 字典序排序后处理，与数组排列无关；
2. **固定遍历顺序**：所有网格按行主序（y 外 x 内）访问，无并行、无 Map/Set 迭代；
3. **Float64 累加器**：中间累加在 `Float64Array` 中完成，最后一次性转 `Float32Array`，避免写序敏感的舍入差异；
4. **无环境输入**：不使用 `Date`、`Math.random`、GPU 并行或任何平台相关函数；
5. **雪量守恒**：每台枪的高斯权重在包围盒内归一化，网格内沉积体积 ≈ 出雪量 × 时长（截断误差 < 2%）。

验证手段：

- 单元测试 `test/snow.test.ts`：双跑哈希、乱序哈希、守恒、漂移、零枪、1024 性能基线；
- 造雪页每次计算可选「双跑比对」，页面显示两次 FNV-1a 哈希；
- 设置页提供一键自检；导出的 BIN 侧车 JSON 内含厚度哈希，可跨机器核对。

## 1024² 编辑性能

- 高度图为行主序 `Float32Array`，刷子只访问半径包围盒内像素（半径 30 约 2800 格），单次盖印 < 4ms（见测试基线）；
- 拖拽时按笔刷半径 35% 间距插值打点，快速移动不留空洞；
- 2D 俯视渲染固定输出 512² 离屏画布并按 `requestAnimationFrame` 节流，编辑期间不重算全分辨率；
- 全量积雪计算在 Web Worker 中运行，不阻塞 UI。

## 积雪模型

每台造雪机在地面形成二维各向异性高斯堆积体：

- 风使中心沿风向漂移 `风速 × 漂移系数 × 时长`，顺风方向 sigma 展宽；
- 喷射张角决定横向 sigma，射程决定包围盒截断半径；
- 厚度（米）= 归一化权重 × 单枪雪量 / 格点面积，多枪结果线性叠加。

模型参数全部暴露在 UI 上，可按现场经验标定。

## 目录结构

```
src/
  domain/        纯函数领域层（无 DOM 依赖，可直接单测）
    snow.ts        确定性积雪引擎
    terrain.ts     刷子 + value-noise fBm
    slope.ts       坡度分析与分区统计
    grooming.ts    车辙栅格化
    sun.ts         太阳位置/色温
  render/        WebGPU 渲染器与 WGSL 着色器
  editor/        2D 俯视画布与离屏图层渲染
  workers/       造雪计算 Worker
  storage/       IndexedDB、JSON 导入导出、PNG/BIN/CSV 导出
  ui/            路由、布局与六个页面
test/            Vitest 测试
```

## 持久化与数据格式

- 雪场存于 IndexedDB（库名 `ski-resort-planner`），高度图以 `Float32Array` 结构化克隆存储；
- 导出 JSON 为版本化信封（`format/version` 字段），高度图用 base64 小端 float32 字节，导入时做字节数校验；
- 厚度图同时导出灰度 PNG（可视化）与 `.bin` + `.meta.json`（原始数据，含哈希与工况参数）。
